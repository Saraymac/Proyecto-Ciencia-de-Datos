# Predicción de clientes interesados en depósitos a plazo

**Proyecto final de Ciencia de Datos**

## 1. Descripción del proyecto

El presente proyecto tiene como finalidad analizar información de clientes que recibieron campañas telefónicas bancarias, con el propósito de identificar las características relacionadas con la contratación de depósitos a plazo.

Mediante técnicas de aprendizaje automático se desarrollarán y compararán diferentes modelos de clasificación para predecir si un cliente contratará este producto financiero.

## 2. Objetivo general

Desarrollar y evaluar modelos de clasificación que permitan predecir la contratación de depósitos a plazo a partir de las características de los clientes y la información obtenida durante las campañas telefónicas.

## 3. Algoritmos utilizados

- Naive Bayes.
- Máquinas de soporte vectorial (SVM).
- Perceptrón multicapa (MLP).

## 4. Conjunto de datos

**Bank Marketing**

Se utiliza el conjunto de datos Bank Marketing, que contiene información relacionada con clientes y campañas de marketing telefónico de una institución bancaria.

Archivo principal: `bank-full.csv`.
